## ✨ What is TaskFlow?

TaskFlow is a cloud-based project management platform designed for software teams to organize projects, manage sprints, assign tasks, collaborate in real time, and monitor progress from one beautiful dashboard.

Inspired by tools like **Jira**, **Asana**, and **Monday.com**, TaskFlow focuses on providing an intuitive experience while implementing modern full-stack architecture from scratch.

# 🚀 Getting Started

## Backend

```bash
cd taskflow-backend

./mvnw clean install

./mvnw spring-boot:run
```

---

## Frontend

```bash
cd taskflow-frontend

npm install

npm run dev
```
